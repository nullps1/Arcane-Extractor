# Security Policy

## Supported versions

Only the latest release receives fixes.

| Version | Supported |
|---|---|
| 1.0.x (latest) | Yes |
| Earlier | No |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email **noah@weeksitsolutions.com** with:

- what the problem is and which version is affected;
- steps to reproduce it, or a proof of concept;
- the impact you expect, for example item duplication on a server, a crash triggered by a client, or privilege abuse.

You will get an acknowledgement within 7 days. This is a small hobby project maintained by one person, so fix times vary, but reports are triaged by severity and you will be told the outcome. Reporters are credited in the changelog unless they prefer not to be.

## Scope

In scope: the mod's block, menu and network payload, and its server-side validation, such as bypassing the extraction checks, duplicating items, or crashing a server from a client.

Out of scope: vulnerabilities in Minecraft, NeoForge or other mods, and problems that need operator access to the server.
